# 🧭 Quick Start

AWAvenue Ads Rule blocks ads, analytics, and unwanted connections at the network level, so you don't need per-app rules. It works with the popular filtering and proxy tools on phones, computers, and routers.

## What it blocks

| Category | Covers |
|---|---|
| Ads | Ad serving, bidding, creatives, and attribution |
| Privacy | Analytics, telemetry, crash reporting, and fingerprinting |
| Unwanted | Forced updates, P2P/PCDN, push, and remote configuration |

The builder asks whether to block privacy and unwanted; together that makes four profiles. If you only want ads gone without affecting push and updates, answer "no" to both for the ads-only profile.

Domain rules can't remove ads served from the same domain as the content, or the empty space left behind; watch-an-ad-for-a-reward flows aren't considered.
